# Ozon AI 图文素材工具 MVP

这版工具走破局 API 的 OpenAI 兼容网关，不直接连 OpenAI。

- 默认接口地址：`https://breakout.wenwen-ai.com/v1`
- 支持批量生成竖版商品图
- 支持生成 3:4 成品图
- 支持生成标题、描述、卖点文案
- 支持导出 Excel 汇总表

## 当前流程

1. 选择总目录，自动遍历下面的货号子文件夹
2. 每个货号目录里的原图逐张调用图片接口生成对应 AI 图
3. AI 图保存到竖版输出目录
4. AI 图转换为 3:4 图
5. 生成文案时，默认读取 `3:4 输出目录` 下该货号目录里排序后的第一张图片
6. 用标题提示词生成标题
7. 用卖点文案提示词生成描述和 5 条卖点
8. 保存 `json`、`txt`
9. 如果开启 `导出 Excel 汇总表`，批处理结束后会在文案输出目录生成 `ozon_content_export.xlsx`

## 启动

```bash
python3 app.py
```

## 输出结果

- 竖版 AI 图：`AI输出目录/SKU001/原文件名_ai_vertical.png`
- 3:4 AI 图：`3:4输出目录/SKU001/原文件名_ai_portrait.png`
- 原图转 3:4：`3:4输出目录/SKU001/原文件名_3x4.png`
- 文案 JSON：`文案输出目录/SKU001/SKU001_content.json`
- 文案文本：`文案输出目录/SKU001/SKU001_content.txt`
- Excel 汇总：`文案输出目录/ozon_content_export.xlsx`

## 说明

1. 每张原图都会单独调用一次图片接口。
2. 有参考图时优先走 `/images/edits`。
3. 如果参考图编辑失败，会自动回退成文生图。
4. 如果图片接口返回 URL，程序会自动重试下载。
5. 标题和描述/卖点是两次独立的 `/chat/completions` 调用。
6. Excel 汇总表包含 `sku`、`货号`、`标题`、`简介`、`json富文本内容`、`是否上传成功`。
7. 图片和文案支持使用不同的 Key，文案模型默认是 `gpt-5-high`。
8. 如果选择了水印图片，所有生成的 3:4 图片都会在左下角自动贴上该图片水印。
